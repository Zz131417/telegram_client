# 使用指南

本指南面向第一次使用的用户，介绍如何登录、各平台如何安装，以及基础功能怎么用。

---

## 一、登录流程

打开 App 后，会先进入**登录页**，让你选择凭据来源，再按 Telegram 的授权流程走完：

1. **选择凭据来源**
   - **官方凭据**：使用 App 内置的公开凭据，点一下即可登录（按平台自动选择，iOS 上会让你在两项里挑一个）。
   - **自己输入凭据**：填入你自己的 `api_id` / `api_hash`（推荐，见下方说明）。
   - **仅预览 UI**：不登录，直接看完整界面和动画。
2. **输入手机号**（含国家码，如 `+86...`）
3. **输入验证码**（Telegram 会发到你的 App 或短信）
4. **输入两步验证密码**（如果账号开启了 2FA）
5. 完成，进入聊天列表 ✅

> 💡 **关于凭据**：「官方凭据」是 Telegram 官方 / 关联项目注册的公开共享值（api_id 如 `4`、`2040`、`21724`），多人共用可能被限流或封号。
> **强烈建议用自己的**：打开 https://my.telegram.org/apps ，用手机号登录后创建一个应用，约 2 分钟免费拿到 `api_id` 和 `api_hash`，然后在登录页选「自己输入凭据」填进去即可。

## 二、各平台安装方式

下载地址统一在仓库 **Releases** 页（每个版本附带 Android×3 / Wear OS / Windows / Linux / iOS 模拟器 / iOS 未签名 IPA 共 8 个产物）：

| 平台 | 安装方式 |
|------|----------|
| **Android** | 下载 APK，允许「未知来源」后点击安装 |
| **Wear OS 手表** | 用手表侧载工具（如 Wear Installer）把 APK 装到手表，需 Wear OS 4 及以上 |
| **iOS / iPad** | 下载未签名 IPA，用 AltStore / Sideloadly / ESign 侧载（这些工具会替你重签） |
| **iOS 模拟器** | 拖入 Xcode 模拟器即可 |
| **Windows** | 解压 zip，运行里面的 `.exe` |
| **Linux** | 解压 tar.gz，运行里面的可执行文件 |

> 未签名 iOS 包无法在库存真机直接安装，必须经侧载重签。

## 三、基础功能

- **聊天列表**：展示会话，未读消息有角标，点击进入对话
- **会话详情**：发送 / 接收消息，进出场有动画，已读回执可见
- **主题切换**：亮色 / 暗色 / 跟随系统，在「设置」中切换
- **日志**：聊天列表右上角菜单 → **日志**，可查看、复制、清空运行日志，遇到登录问题可在这里排查

## 四、代理、插件与导入导出

聊天列表右上角 **设置**（齿轮图标）里可以管理这些功能。

### 代理
- 进入 **设置 → 代理**，选择 SOCKS5 或 MTProto，填写服务器、端口、用户名 / 密码（可选）。
- 点「保存并应用」后配置会持久化；**真实登录后**代理会即时下发到 TDLib 生效（预览模式下仅保存）。
- 也可在代理页「清除代理」。

### 插件
- 进入 **设置 → 插件管理**，内置可启停的模块：
  - **紧凑气泡**：减小聊天气泡内边距，单屏显示更多内容（实时生效）。
  - **调试日志浮窗**：在聊天页显示一个可展开的小浮窗，实时查看最近日志（实时生效）。
  - **隐藏已读回执** / **禁止自动下载**：预留开关，真实登录时再扩展其行为。
- 启停状态会持久化，重启后保留。

### 导入 / 导出配置
- 进入 **设置 → 导入 / 导出配置**：
  - **导出**：把当前「代理 + 主题 + 已启用插件」序列化为 JSON，可一键复制。
  - **导入**：粘贴同样的 JSON，应用代理 / 主题 / 插件状态（主题即时生效，其余持久化）。
- 方便在多设备间迁移设置，或备份。

## 五、常见问题

**Q：点了登录提示「加载 libtdjson 失败」？**
A：说明当前安装包没有自带原生库。请从 Releases 下载对应平台的最新构建（已自带），或参考开发文档自行打包。

**Q：用「官方凭据」登录后收不到消息？**
A：共享凭据可能被 Telegram 限流，建议改用自己申请的 `api_id` / `api_hash`（见第一节）。

**Q：iOS 装不上？**
A：未签名 IPA 必须侧载重签，不能直接安装到库存真机。用 AltStore / Sideloadly / ESign 即可。
